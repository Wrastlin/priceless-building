# Scene to Higgsfield map

Remotion is the conductor. It owns the approved timeline, factual typography, scene cuts, safe areas, image crops, and final assembly. Higgsfield is an optional plate service for a named scene after the Remotion mock is approved.

No recipe in this document authorizes a paid run. Every Higgsfield entry is prompt-only until Aaron approves the exact source, tool, prompt, duration, aspect ratio, displayed credit cost, and rejection criteria.

## Product hero

**Remotion owns**

- 35-frame hero beat in `PL-sku-micro-v1`
- Product scale, crop, contact shadow, cream field, rust rule, cut timing
- Full-frame product prominence and deterministic image placement

**Higgsfield recipe when needed**

- `remove_background` to create or repair an RGBA master
- Studio clean only when the source needs glare or background cleanup
- Optional Hyper Motion product plate, prompt-only, for a restrained light sweep after the still mock is approved

**Inputs**

- `productSrc`: approved cutout PNG or clean studio image
- `title`: item record title for alt text and scene identity
- Original item image as fidelity reference

## Name stack

**Remotion owns**

- Montserrat 300 `INTRODUCING` and subtitle line
- Montserrat 700 item title
- Ink field, angled parchment reveal, crop, opacity, and cut

**Higgsfield recipe when needed**

- None by default
- Optional Vibe Motion prompt-only reference for a background matte
- Never bake item title into generated pixels

**Inputs**

- `title`
- `subtitle`
- `productSrc`

## Brand and facts

**Remotion owns**

- Brand lockup, title, description, dimensions, and verified price
- Rust price treatment, two-column layout, product pullback, end timing
- Conditional omission of empty dimensions or price

**Higgsfield recipe when needed**

- None
- Vibe Motion may supply a non-text graphic matte only after approval

**Inputs**

- `brand`
- `title`
- `description`
- `dimensions`
- `price`, formatted only from a verified item record
- `productSrc`

## Finish field

**Remotion owns**

- Finish color field, 300/700 type stack, scene duration, silhouette grade
- Verified finish name and final lockup

**Higgsfield recipe when needed**

- Optional Hyper Motion product mode, prompt-only, for a subtle material light pass
- Reject any color shift that changes the recorded finish

**Inputs**

- Cutout PNG
- Verified item `color`, `material`, or finish spec
- `title`, `brand`

## Detail crop

**Remotion owns**

- Crop window, scale, mask, callout position, cut timing
- Dimension lines and labels from verified records

**Higgsfield recipe when needed**

- Studio clean for reflections or edge contamination
- Optional Hyper Motion product mode, prompt-only, for a controlled highlight
- No generated hardware, holes, grain, panel detail, or fixtures

**Inputs**

- Full-resolution cutout or studio master
- Approved crop coordinates
- Verified `dimensions`, `material`, `color`, and `specs`

## End card

**Remotion owns**

- Brand lockup, address, URL, phone, final product hold, loop point
- All type, hierarchy, timing, and platform-safe margins

**Higgsfield recipe when needed**

- None
- Vibe Motion prompt-only can be used as a motion study, but production type stays native in Remotion

**Inputs**

- Brand id
- Approved business contact constants
- Optional `productSrc`
- Verified price only when the template calls for it

## Gate for any future Higgsfield plate

1. Approve the Remotion scene still and frame range.
2. Name the exact cutout or studio source.
3. Name one skill: `remove_background`, studio clean, Vibe Motion, or Hyper Motion product mode.
4. Keep every factual word and number in Remotion.
5. Record the prompt, output length, aspect ratio, displayed cost, and rejection rules.
6. Get explicit approval for that one run.
7. Return the approved plate to Remotion for final assembly.

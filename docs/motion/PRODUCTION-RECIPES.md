# Production recipes — how every deliverable was made (2026-07-22)

Every deliverable in `PRICE-LESS DELIVERABLES/` maps to an exact, repeatable recipe below. Nothing is hand-magic; it is all prompts, manifests, and commands in this repo. Paths relative to `priceless-building/`.

**Why recipes exist (the compounding library, Aaron 2026-07-23):** one store photo seeds a permanent base — master, cutout, placements, variations, text details — and every video is built FROM that base, never from scratch. Recipes are what make the base re-runnable: when a new technique or model arrives, we point it at the existing library and regenerate at scale ("use my existing library and go explore this new route"). So: never overwrite originals (version alongside), keep one slug per product everywhere, log every new deliverable class here the day it ships, and when adopting any new tool ask first what it produces when batched across the whole base. Full statement in `MASTER-EXECUTION-PLAN.md`.

## The shared foundations

1. **Studio master** (per product): `node scripts/gemini-isolate.mjs <photo> renders/gemini-studio/<slug>-gemini.png`. The glass-safe studio prompt lives inside that script. ~2 cents. Fidelity grades in `PRODUCT-PREP.md`.
2. **Alpha cutout**: `higgsfield generate create image_background_remover --image <master> --wait` (1 credit), curl the URL into `renders/gemini-cutouts/`, then `magick <cutout> -trim +repage motion-remotion/public/products/trim/<slug>-trim.png`.
3. **Placement scene** (per product): `node scripts/gemini-place.mjs <master> renders/placements/<slug>-placement.png "<room context>"`. The scene prompt template is inside the script; the per-product contexts (with CRITICAL signature-feature protection) are stored in `motion-remotion/scripts/feed-manifest.json`. ~2 cents. ALWAYS view the output: check for people, changed hardware, wrong pane counts.
4. **Type system** (locked from Kohler references): Playfair Display italic 400 46px lead, Playfair 400 128px display name (104px when name is longer than 10 chars), Montserrat 300 26px descriptor at 0.52em tracking, hairline-flanked Montserrat 300 20px tag at 0.42em. White with soft text shadow over imagery. Implemented once in `src/scenes/FeedPostV2.tsx` and mirrored in `src/scenes/OneRoofSerif.tsx`.
5. **Mac-safe encode** (every deliverable): ffmpeg `-vf "scale=out_color_matrix=bt709:out_range=tv,format=yuv420p,setparams=color_primaries=bt709:color_trc=bt709:colorspace=bt709" -c:v libx264 -crf 16 -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv -movflags +faststart -an`.
6. **Verification** (every deliverable): extract frames with ffmpeg select, view them, run `python3 motion-remotion/scripts/verify-mp4-not-black.py`, montage labeled contact sheets on #f5f0e6 with `/System/Library/Fonts/Supplemental/Arial.ttf`.

## Per-deliverable recipes

- **01 Feed Posts** (`PL-feedv2-<slug>.mp4`, 1080x1350, 3.5s): comp `PL-feed-post-v2` + placement scene + manifest copy. Driver: `python3 motion-remotion/scripts/render-feed-v2.py [slug...]`. Copy lives in `feed-manifest.json` (name/descriptor/anchor per product).
- **02 Text Stories** (`PL-story-*.mp4`): same comp, custom `--props` JSON (intro/name/descriptor/tag). Recipe = the props string; the four shipped examples' props are embedded in the render commands logged in this file's history and re-creatable from the filenames: found (Found at Price-Less/Craftsman/Inventory changes constantly), forless (The best of the best/For Less/Banded crystal chandelier), oneofone (One of one/Paisley/When it is gone, it is gone), oneofakind (One of a kind/Barn Door/With track hardware).
- **03 Textless Plates** (`PL-plate-<slug>.mp4`): `python3 motion-remotion/scripts/render-feed-v2.py --plates [slug...]`. Passes explicit empty text props (empty strings, not omitted, or composition defaults leak in).
- **04 Product Micros** (`PL-<slug>-micro.mp4`, 1080x1920, 3.5s): comp `PL-sku-micro-v1`, driver `motion-remotion/scripts/render-micros.py` (contains the full 21-product manifest with approved copy; cutout used as productSrc AND productCutoutSrc). NOTE: still in the older bold sans voice; serif requiet queued.
- **05 Category Films & Reels**: Doors film = `PL-doors-film-v1` (`src/scenes/DoorsFilm.tsx`, beats hardcoded: hook / trio / two hero cuts / DoorSelectLift aisle beat / two DoorHomeSlam beats into the clean home plates / claim / end card). Reels = `PL-sinks-reel-v1`, `PL-lighting-reel-v1` (`src/scenes/CategoryReel.tsx`, rosters in Root.tsx defaultProps). Render: `npx remotion render <id> out.mp4` + encode chain.
- **06 Placement Scenes**: recipe #3 above; per-product contexts in `feed-manifest.json`. Regenerated variants (copper realistic bath, candelabra high entry hall, craftsman open with knob/deadbolt + 4-pane grid pinned) used one-off contexts recorded in MASTER-EXECUTION-PLAN.md.
- **07 Product Masters & Cutouts**: recipes #1 and #2.
- **08 Music**: `higgsfield generate create sonilo_music --prompt "<brief>" --duration 30 --wait` (1.88 credits). C prompt: light luxurious spa piano + warm upright bass, no drums/percussion/risers/synth. D prompt: elegant minimal piano + soft cello, same exclusions. A/B were earlier warm-minimal / modern-bold briefs.
- **12 Motion Clips** (`clip-<slug>-<action>.mp4`, 5s, ~1440x1788 upscaled): kling3_0 image-to-video on a VERIFIED placement scene. `higgsfield generate create kling3_0 --start-image renders/placements/<slug>-placement.png --prompt "<one physical action>. Camera completely locked unless stated. Keep the room and product geometry exactly as they are, realistic physics, consistent lighting. No people, no hands." --duration 5 --aspect_ratio 9:16 --wait` (~10cr). Action vocabulary proven: door swings open / barn door slides / water pours from faucet / bulbs glow+flicker with slow dolly-in / fire flickers / steam rises. Then Tier 1 polish: `bytedance_video_upscale` (0.2cr, ~860x1068 -> 1440x1788), then the Mac-safe encode chain, then frame-verify (4-frame contact sheet, fidelity/people gate) BEFORE shipping. Raw gens in `renders/motion-clips/`, upscales in `renders/motion-clips/upscaled/`, batch scripts idempotent with append logs (batch2-log.txt pattern).
- **10 One Roof Brand** (`ROOF-serif-oneroof-v1.mp4`, `ROOF-serif-doitall-v1.mp4`, 16s, 9:16): comp `src/scenes/OneRoofSerif.tsx` — beat list as defaultProps in Root.tsx. RULE (Aaron): every beat over a real photo, no bare void cards; the comp applies a soft radial grade behind the type for legibility over bright rooms. V1 spine: One Roof hook > 4 Squared install > Builders Corner install > Price-Less aisle > All Under One Roof close. V2: We do it all hook > Price-Less lighting floor > Builders Corner kitchen > 4 Squared pergola night > One Roof close. Photos: real only, from `public/one-roof/v3-install/` and `v3-a/`. To make another variant: copy a Composition block, change the beats, render.

## To refine anything

Change the manifest entry or the Composition defaultProps, re-render that one id/slug, re-verify frames. Scene changes cost pennies (Gemini); text and layout changes cost nothing. Aaron's taste calibrations live in agent memory `priceless-creative-directives` and section 3b/3c of MASTER-EXECUTION-PLAN.md.

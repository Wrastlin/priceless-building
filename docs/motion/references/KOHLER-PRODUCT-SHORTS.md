## Grammar to steal (from Claude Console)

1. Symmetrical product centerpiece in a designed room (wallpaper, sconces, brass)
2. Brand lockup: KOHLER / STUDIO MCGEE (or Price-Less / Builders Corner)
3. Push-in / detail: legs, P-trap, porcelain rim, towel shelf texture
4. Title card: “Introducing” + product name + category
5. No aisle, no warehouse, no talking head

**Price-Less remake:** real vanity/sink/door cutout → staged graphic room OR cream/ink field → same beat order.
